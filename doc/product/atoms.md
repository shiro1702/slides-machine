# Атомы дизайн-системы слайдов

Источник: [brainstorm 02.08 INDEX](../brainstorms/02.08.2026-INDEX.md) · сырьё [02.08.2026-atoms.md](../brainstorms/02.08.2026-atoms.md).

Цель: не рисовать счётчик, лейбл и @handle заново в каждом из 14×3 макетов. Правка «подвинь хэндл на 8px» = одно место.

## Три слоя

| Слой | Что | Кто знает про внешний вид |
|------|-----|---------------------------|
| **TOKENS** | цвета, шрифты, отступы, радиусы | Brand Theme + layout spacing |
| **ATOMS** | повторяющиеся детали | variant из layout-стиля |
| **TEMPLATES** | 14 типов × варианты раскладки | только контент + какие атомы нужны |

Правило чистоты: **шаблон никогда не передаёт атому внешний вид — только данные.**

```
Шаблон:  <SlideCounter index={2} total={7} />
Стиль:   clean_minimal → «03 — 07» моно muted
         bold_marketing → чип [3/7] accent/onAccent
```

| Атом | Варианты |

| `SwipeHint` | «листай →» · стрелка · шеврон (обычно 1-й / последний) |

| Атом | Роль |
|------|------|

|------|------|

Эти ~14 атомов покрывают служебку всех 42 макетов (14 типов × 3 варианта). В шаблоне остаётся только уникальная раскладка контента.

## SlideFrame — общая рама

Служебные элементы стоят в одних местах → общий контейнер со слотами:

```
┌─────────────────────────────────┐
│ topLeft            topRight     │  Label / counter
│                                 │
│           CONTENT               │  шаблон типа
│                                 │
│ bottomLeft        bottomRight   │  AuthorBadge / Counter / SwipeHint
└─────────────────────────────────┘
```

`SlideFrame` сам:

- ставит поля (напр. 96px из токенов), фон, safe-zones;
- раскладывает атомы по слотам согласно **chromeLayout** стиля;
- знает исключения: на HOOK автор крупнее, на CTA счётчик не нужен.

Раскладка слотов — часть layout-стиля (не шаблона типа).

## Структура пакета (целевая)

```
/packages/slides   (или remotion/layouts + shared)
   /tokens            цвета, шрифты, spacing
   /atoms             SlideCounter, AuthorBadge, Label, …
   /chrome
      SlideFrame.tsx
   /templates         14 типов × варианты контента
   /styles
      clean_minimal.ts   # tokens + atom variants + chromeLayout
      bold_marketing.ts
      …
   renderSlide.tsx    (type, variant, data, style, brand) → JSX
```

Атомы = чистый React → одинаково в редакторе, html-to-image и Remotion. В рилсах анимируются атомарно («counter fade-in», «hairline растёт») один раз для всех шаблонов.

## Экономика

| Подход | Объём |
|--------|-------|
| Без атомов | 14 типов × 3 варианта × 5 стилей ≈ **210** реализаций служебки |
| С атомами | 14 атомов × ~3–4 варианта ≈ **~50** кусочков; шаблоны собирают бесплатно |

- Новый стиль ≈ токены + мэппинг вариантов атомов (~1 файл, полдня)  
- Новый тип слайда ≈ только контентная часть (~полдня)  
- Правка хэндла = 1 место (`SlideFrame` / `AuthorBadge`)

## Порядок внедрения

1. 14 атомов в варианте `clean_minimal` (1–2 дня)  
2. `SlideFrame` + chromeLayout (полдня)  
3. Переложить типы слайдов на атомы — контентная часть (2–3 дня)  
4. **Второй стиль как проверка:** если `bold_marketing` собирается за полдня без правки шаблонов — архитектура верная  
5. Brand Kit в БД + тумблеры в редакторе (`showCounter`, `showAuthor`)

Следующий шаг (не сделан в брейншторме): спека props / размеров каждого атома в px как ТЗ для вёрстки.
