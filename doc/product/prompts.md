# AI-промпты

Черновики из brainstorm. Живые промпты — в `packages/ai/prompts/` когда появится код.

## Карусель из темы

```
Ты эксперт по созданию вирусных каруселей для соцсетей (VK, Telegram, Instagram*).

Создай структуру карусели на тему: [ТЕМА]
Аудитория: [АУДИТОРИЯ]
Тон: [экспертный/дружелюбный/…]
Ниша: [SMM|эксперт|недвижимость|…]
Цель поста: [польза|ошибки|чеклист|кейс|продажа]
Количество слайдов: [N]
Шаблон: [Expert List|Mistakes|…]

Верни ТОЛЬКО валидный JSON по схеме project/carousel
(slides с layout, headline, body, CTA; без markdown-обёртки).
Тексты короткие, разговорные, на русском.
Первый слайд — сильный хук.
```

Параметры ниши/тональности/цели — Sprint 3.

## Сценарий Reels (позже)

См. сырой brainstorm: Hook / Scene / CTA в Markdown + YAML frontmatter;  
промпты: генерация сценария, нормализация в md, съёмочный лист, разметка raw-файлов, edit.json, QC плана.

## Правила для рилс-структуры

- Хук в первые 2 с  
- Бюджет 15–30 с  
- Визуальные смены каждые 2–4 с  
- CTA в конце
