# Video carousels и сценовые рилсы

Источник: «рилс = карусель во времени».

## Общее с каруселью

Тема, бренд, layouts, элементы — те же. Добавляется временной слой.

| Слой | Карусель | Рилс |
|------|----------|------|
| Формат | 1080×1350 | 1080×1920 |
| Время | нет | duration на сцену |
| Анимации | опц. | in/loop/out |
| Переходы | нет | fade/slide/zoom… |
| Аудио | нет | music (+ voiceover/sfx) |
| Safe zones | нет | да (UI соцсетей) |

## Что отлично ложится (faceless)

Текстовые рилсы, листиклы, цитаты, статистика, before/after, фото-слайдшоу (тревел, недвижимость).

## Что не на этом этапе

Talking head, нарезка длинных, мультикамера, дубли → [reels-automation.md](./reels-automation.md).

## UX

Та же лента сцен + 3 контрола: длительность, пресет анимации, музыка.  
Не CapCut-таймлайн.

## Порядок внедрения

1. `timing` + `animation` в схеме (даже «мёртвые»)  
2. Remotion Player: карусель как слайдшоу  
3. Пресеты анимаций  
4. MP4 без звука («анимированная карусель») — апселл Pro  
5. Музыка (royalty-free / Mubert; не треки из TikTok)  
6. 9:16 + safe zones  
7. TTS + субтитры (v2)  

## Правила продукта

- Первая сцена = хук 1.5–2 с  
- Цель 15–30 с (5–8 сцен × 2–4 с)  
- Layouts 4:5 → 9:16 = отдельные координаты, не stretch  

Маркетинг: «одна тема → карусель + рилс» — дифференциатор.
