# Контент: Reels и Build-in-Public

## 5 каналов

1. Reels/Shorts — верх воронки  
2. Telegram Build-in-Public  
3. TG-чаты / комьюнити  
4. Микроинфлюенсеры  
5. Рефералка в боте  

## Частота (старт)

1–2 коротких видео/день · 1 TG-пост/день · 3–5 каруселей/нед · 1 большой BIP/нед.  
Месяц: 30–60 Reels, 30 постов, 10–15 каруселей, 4 больших поста о разработке.

Приоритет RU: TG-канал → Reels → VC.ru → чаты SMM → партнёрки.

## Форматы Reels

1. **Тема → карусель** (0–2 «написал фразу» → TG → генерация → результат → CTA в бот)  
2. **Контент за 60 сек** под нишу  
3. **Разбор плохого поста** → бот упаковал  
4. **До/после**  
5. **Идеи по нишам** + «бот делает такие автоматически»  
6. **Ошибки контента** + мягкий продукт  

## Матрица

| Тип | Цель |

| До/после | вау |

## Build-in-Public

Не только «написал код» — сериал о продукте: прогресс, метрики, ошибки, голосования, публичный roadmap.

Пример метрик недели: юзеры, карусели, экспорты, 3+ проектов, запросы оплаты.

## Чаты — без спама

«Нужны 10 SMM для закрытого теста, бесплатно за фидбек» + пример карусели + «сгенерирую 5 в комментариях».

## Микроинфлюенсеры 3–30к

Pro-доступ, промокод, % , совместный кейс (5 тем → бот → публикация).

## Лид-магниты внутри продукта

Ниша → 20 тем → выбрать → карусель. Сильнее PDF.
