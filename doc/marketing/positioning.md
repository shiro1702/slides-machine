# Позиционирование

## Не говорим

«AI-генератор каруселей» / «заменим SMM».

## Говорим

> Telegram-бот, который за 2 минуты делает карусель или рилс для эксперта / SMM / бизнеса.  
> Без Canva, без дизайнера, без долгих промптов.

Или: контент-помощник в Telegram — тема → карусель → рилс → публикация.

Ставка: **скорость + привычный TG UX**, не «ещё AI».

Шире Instagram*: VK, Telegram, Дзен, соцсети (с дисклеймером где нужно).

## Сегменты

| Сегмент | Боль | Оффер |
|---------|------|--------|
| SMM | много контента дёшево и быстро | карусели для клиентов в 3× быстрее |
| Эксперты / коучи | есть экспертиза, нет упаковки | мысль → карусель за 2 мин |
| Риелторы | подборки, ошибки, обзоры ЖК | из темы/объекта → пост/рилс |

## Обещания (формулировки)

1. Из одной мысли — готовая карусель  
2. Из поста — рилс  
3. Из длинного текста — 7 слайдов  
4. Из экспертности — контент на неделю  
5. Из TG-сообщения — готовый визуал  

Дифференциатор: **одна тема → карусель + рилс** (конкуренты обычно умеют одно из двух).
