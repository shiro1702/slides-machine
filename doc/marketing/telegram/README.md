# Telegram-воронка

```
Reels / пост / чат / рекомендация
        ↓
Telegram-бот  (/start, ref_)
        ↓
ниша → тема → карусель
        ↓
редактирование / экспорт
        ↓
повтор → лимит → оплата / early access
```

Лендинг — вспомогательный. Весь трафик MVP → бот.

## /start

Короткий текст + примеры тем + `[Сделать карусель] [Примеры] [Как это работает]`.
