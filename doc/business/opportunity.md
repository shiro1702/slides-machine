# Перспективность и проверка спроса

Источник: оценка идеи в brainstorm 25.07.2026.

## Вердикт

Идея **рабочая, не уникальная**. Рынок есть; конкуренция высокая.  
Браться стоит при **нише / скорости / дистрибуции**, не как «ещё один AI-генератор».  
Потенциал нишевого бизнеса: ориентир **$3–20k MRR**. Венчур без сильного угла — слабый.

## Рынок

Платят: aiCarousels, PostNitro, Contentdrips; Taplio (LinkedIn); OpusClip/Captions (видео); Canva.  
Лучший сегмент: **SMM и агентства**. Эксперты — платят, высокий churn. SMB — мало.

RU: конкуренты англоязычные, слабая кириллица → возможный угол. Прямые RU: SUPA, Flyvi, Holst.

## Риски

1. Canva / нативный AI соцсетей съедают «красивые шаблоны»  
2. GPT-wrapper: промпты не защищают → защищают шаблоны, UX, дистрибуция  
3. AI-контент выглядит «как AI» → retention = главная проблема категории  
4. Полный talking-head Reels — месяцы и GPU; не стартовая ставка  
5. Vitamin для многих → churn 8–15%/мес нормален  

## Плюсы нашего угла

- Лестница карусели → video → reels логична  
- Один JSON + Remotion → карусель+рилс (дифференциатор)  
- Video→carousel repurposing сильнее «тема→слайды»  
- Telegram-native UX для RU  

## Углы победы

| | Угол |
|--|------|
| A | Ниша (риелторы / психологи / …) |
| B | Repurposing: одно видео → неделя контента |
| C | B2B агентства: brand kits, batch, approve |

## Дешёвая проверка (2–4 недели)

1. Ручной пайплайн: Groq → JSON → Remotion → PNG (без кабинета)  
2. 10–15 экспертам/SMM бесплатно или символически  
3. Сигналы: **опубликовали без переделок**; **вернулись сами**  
4. 5+ из 15 вернулись → строить продукт; иначе сменить нишу, не писать больше кода  

Не уходить в архитектуру вместо спроса.
