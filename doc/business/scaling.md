# Масштабирование — триггеры

## Продукт

| Триггер | Действие |
|---------|----------|
| 10–20: usable carousel ≤3 мин | Sprint 3–4: кнопки, Mini App |
| 30–50: сами правят и экспортируют | лимиты, история, MP4 |
| Early pay / «хотят рилсы» | Sprint 6+ |
| Retention + оплаты | brand kits, agency, video ingest |
| Mini App упирается / Photos | companion app — не раньше |

## Инфра

| Триггер | Действие |
|---------|----------|
| MP4 / FFmpeg | VPS 8 vCPU + очередь + S3 |
| Neon cold start мешает | Paid / свой Postgres |
| Коммерческий трафик | Vercel Pro или RU VPS |
| Bandwidth | только signed URL |

## Бизнес

| Триггер | Действие |
|---------|----------|
| 10–20 платящих + кейсы УУ | посевы на всю RU |
| Churn высокий | контент-планы, рилсы Pro, onboarding бота |
| 200+ платящих | поддержка / agency всерьёз |

## Принцип

Не ждать видео, чтобы звать людей. Первый тест: **тема → карусель → media group**.
