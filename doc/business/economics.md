# Экономика

Источник: расчёт для соло + Cursor, старт Улан-Удэ (brainstorm).

## Главный вывод

Улан-Удэ = **тестовый полигон**, не рынок. Экономика — на всей RU.  
Себестоимость карусели **~2–7 ₽**, маржа высокая. Главные затраты — **время и продажи**.

## Вводные

Команда: 1 + Cursor + AI · Freemium · пилот УУ → RU.

## Старт деньгами

| Статья | Сумма |
|--------|--------|
| Домен | 300–2 500 ₽/год |
| ИП (для ЮKassa) | 0–5 000 |
| Оферта / ПДн | 0–15 000 |
| Шрифты OFL / стикеры | 0–5 000 |

Время MVP: **2–3 мес** full-time (условная упущенная выгода 300–750к).

## Юнит: 1 карусель (8 слайдов)

| | ₽ |
|--|---|
| LLM + регенерации | ~1.5–6 |
| Рендер + трафик | ~0.2–0.8 |
| **Итого** | **~2–7** |

Активный юзер 15–30 каруселей → 50–200 ₽/мес себестоимости.  
Подписка 600–1500 → маржа 80–95%.  
С видео: 10–40 ₽/проект, нужнее мощный worker.

## Улан-Удэ

~100–300 реально платящих потенциально; потолок ~40к MRR.  
Роль: 10–20 клиентов, фидбек, кейсы + услуги «под ключ» 30–50к как подушка.

## Сценарии ~мес. 6

| | Пессимист | База | Оптимист |
|--|-----------|------|----------|
| Платящих | 15 | 60 | 200 |
| MRR | ~9к | ~48к | ~180к |

Безубыточность ~10–20 платящих. «Зарплата» ~200–350 (федеральный масштаб).  
LTV/CAC сходимо при churn &lt; ~15%.

## Чего нельзя забыть

1. Платежи РФ (не Stripe); рекуррент отваливается → retry  
2. Instagram* в РФ — позиционировать шире (VK, TG, Дзен)  
3. Оплата/доступ зарубежных LLM  
4. 152-ФЗ, оферта, лицензии шрифтов/стока  
5. 40% времени после запуска — продажи/контент, не только код  
6. Telegram Stars vs сайт-биллинг ([../project/BOT_MESSENGERS.md](../project/BOT_MESSENGERS.md))  
7. Очередь рендера, абузы free, iOS Safari с дня 1
