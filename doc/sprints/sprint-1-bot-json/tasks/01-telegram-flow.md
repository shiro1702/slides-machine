# 01 — Telegram-flow создания проекта

Реализовать короткий предсказуемый диалог без отдельной регистрации.

**Фича:** F1.1 · **Зависимости:** Sprint 0 bot webhook и meta ниш/стилей

## Scope

- `/start`: ценность, примеры тем, кнопки «Сделать карусель», «Примеры», «Как это работает»
- `/new`: ниша → тема свободным текстом → один из 3 стилей → подтверждение запуска
- Серверное состояние flow, привязанное к `telegram_id`
- `/cancel` и безопасный рестарт незавершённого flow

## Done when

- [x] Новый Telegram user создаётся или переиспользуется по уникальному `telegram_id`
- [x] Callback data стабильна, коротка и валидируется на сервере
- [x] Повторные update/callback не создают дубликаты проекта
- [x] Потерянное/просроченное состояние приводит к понятному restart, а не exception
- [x] Все 3 ниши и 3 стиля доступны из meta Sprint 0 без дублирования констант
- [ ] Flow вручную пройден на mobile и desktop Telegram *(нужен live env)*
