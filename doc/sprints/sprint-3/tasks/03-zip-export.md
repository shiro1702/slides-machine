# 03 — ZIP-export PNG

Дать пользователю переносимый набор исходных слайдов для сохранения и публикации.

**Фича:** F1.5 · **Зависимости:** Sprint 2 Blob outputs, task 02 versions

## Scope

- ZIP из PNG конкретной project version (**серверная сборка** из Blob — путь после Remotion)
- Имена файлов с нулевым padding в порядке scenes
- Manifest с project/version/format без чувствительных данных
- Выдача через Telegram document или временную ссылку

> Клиентский html-to-image ZIP (путь A) — **Sprint 4**, не замена этого task: здесь юзер ещё может не открывать редактор.

## Done when

- [ ] ZIP содержит все и только outputs выбранной completed version
- [ ] Порядок файлов сохраняется при лексикографической сортировке
- [ ] Повторный запрос переиспользует готовый export или создаёт его идемпотентно
- [ ] Неполный/failed render нельзя скачать как успешный ZIP
- [ ] Доступ к export проверяет владельца и не раскрывает постоянный публичный URL без необходимости
- [ ] Export укладывается в Telegram limit либо бот выдаёт корректную ссылку
