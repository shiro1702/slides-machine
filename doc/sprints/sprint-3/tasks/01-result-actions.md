# 01 — Действия с готовым результатом

Добавить управляемые действия после album без превращения чата в полноценный редактор.

**Фича:** F1.5 · **Зависимости:** Sprint 2 delivery, task 02 для версий

## Scope

- «Другой вариант»: повторная content generation с теми же входными параметрами
- «Измени текст»: одно текстовое указание → новая валидная версия
- «Другой стиль»: выбор из 3 styles без повторной content generation
- «ZIP»: запуск export из task 03
- «Редактировать»: waitlist/сообщение до Sprint 4, без ложного обещания готового editor

## Done when

- [ ] Callback однозначно содержит project/action и проверяет владельца
- [ ] Повторный callback идемпотентен и показывает текущий статус
- [ ] Смена style переиспользует content, но создаёт новый render для новой version
- [ ] Text instruction проходит валидацию длины и не меняет чужой проект
- [ ] На каждое действие есть progress, success и recoverable error state
- [ ] Все новые albums сохраняют связь с исходным project и version
