# Sprint 3 — варианты, экспорт и качество

**Статус:** запланирован · **Тест:** продолжение закрытого №1, 3–5 проектов на участника

## Цель

Дать пользователю управляемый второй шаг после первого album: получить вариант, изменить текст/стиль, скачать исходники и вернуться за новой каруселью.

**Roadmap:** завершение [этапа 1 — PNG в Telegram](../../roadmap/ROADMAP.md#1--png-в-telegram) · **Фичи:** F1.5, F1.6, F1.7

## Зависимости

- Sprint 2 доставляет стабильный album и записывает end-to-end события.
- Обратная связь первого теста приоритизирует конкретные проблемы content/visual/UX.

## Чеклист

- [ ] F1.5 — действия «Другой вариант», «Измени текст», «Другой стиль» ([task 01](./tasks/01-result-actions.md))
- [ ] F1.6 — immutable версии проекта и активная версия ([task 02](./tasks/02-project-versions.md))
- [ ] F1.5 — ZIP с PNG и безопасная выдача результата ([task 03](./tasks/03-zip-export.md))
- [ ] Промпты и retry улучшены по данным теста, а не по вкусу команды ([task 04](./tasks/04-prompt-quality.md))
- [ ] F1.7 — воронка и продолжение закрытого теста дают решение по gate этапа ([task 05](./tasks/05-funnel-feedback.md))

## Критерии выхода

- [ ] Пользователь самостоятельно создаёт вариант или меняет стиль и получает новый album
- [ ] Любой повторный export связан с конкретной immutable version
- [ ] ZIP содержит полный упорядоченный набор PNG
- [ ] Можно посчитать первую/повторную генерацию, публикацию и возврат
- [ ] В ретро принято решение о переходе к Mini App либо изменении гипотезы этапа 1
