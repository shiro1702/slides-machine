# 02 — Лимиты + multi-theme

**Фичи:** F2.6, F2.11 · **Зависимости:** F2.9 theme storage

## Scope

| План | Темы | Font pairs |
|------|------|------------|
| Free | 1 своя + пресеты | 3 |
| Pro | 5 | все |
| Agency | 20+ (позже) | + upload позже |

- CRUD тем: имя, цвета, fontPair, handle
- Привязка theme → project; копирование темы
- Лимиты генераций/экспорта (как в business docs) + soft paywall copy
- Enforce на API, не только в UI

## Done when

- [ ] Free не создаёт 2-ю тему; Pro — до 5
- [ ] Upsell-текст объясняет «тема = клиент»
- [ ] Счётчики лимитов видны пользователю
