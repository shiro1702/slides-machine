# 03 — Музыка и кнопка «Сделать рилс»

**Фичи:** F3.3, F3.4

## Scope

- 1–3 royalty-free трека, выбор или default
- Кнопка в боте/Mini App → queue MP4 → отдача файла/ссылки
- Громкость константа; ducking — S10

## Done when

- [ ] Пользователь получает MP4 без ручных действий команды
- [ ] Лицензии треков задокументированы в assets
