# 06 — Палитра из лого и лого на слайдах

**Фича:** F9.1 (часть) · **Зависимости:** multi-theme S5, Blob upload

## Scope

- Upload лого → extract 2–3 доминирующих цвета → 3 предложения палитры
- Пользователь подтверждает → сохраняет как theme
- Опционально: лого на hook / cta / author (токен placement)
- Контраст после extract проверяется так же, как в picker

## Done when

- [ ] Из одного лого можно создать тему за <1 мин
- [ ] Лого не ломает safe area на 1080×1350 и 9:16
- [ ] Нет extract из Instagram URL (позже)
