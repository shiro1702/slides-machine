# Закрытый тест №1 — скрипт (Sprint 2 / task 05)

**Цель:** проверить, нужен ли людям готовый PNG-album, а не техническую новизну.

## Consent (минимум)

Перед стартом коротко:

> Бот сделает карусель по твоей теме. Мы замерим время до результата и спросим 4–5 вопросов. Личные данные не собираем сверх Telegram id (хеш в логах). Можно выйти в любой момент: /cancel.

Не записываем телефоны, email, ссылки на профили без явной просьбы участника.

## Сценарий (модератор не ведёт за руку)

1. Участник пишет `/start` → таймер **T0**.
2. Ниша → тема (своя, реальная) → стиль → подтверждение.
3. Дожидается album в чате → **T1** (первый usable результат = album, который готов хотя бы сохранить).
4. Без подсказок: может ли выложить? Что перепишет?

## Вопросы после результата

1. Понятен ли бот без объяснения? (да / почти / нет)
2. Можно ли выложить как есть? (да / с правками / нет)
3. Что пришлось бы переписать? (текст / визуал / структура / ничего)
4. Хочется ли другой вариант, стиль или ещё одну карусель?
5. Опубликовал(а) ли результат? Вернёшься ли сам(а) за второй?

## Что пишем по каждому участнику

| Поле | Источник |
|------|----------|
| segment | SMM / эксперт / риелтор |
| correlationId | telemetry `flow_started` |
| completion | да/нет до album |
| total_time_sec | T1 − T0 (или из логов: generation + render + delivery latency) |
| outcome | usable≤3м / usable>3м / drop / fail |
| publish | да/нет |
| return_intent | да/нет |

## События в логах (F1.7)

```
flow_started → niche_selected → topic_submitted → style_selected
→ generation_started → generation_succeeded
→ render_started → render_succeeded
→ delivery_started → delivery_succeeded
```

`latencyMs` на generation / render / delivery. Сводка: `scripts/funnel-summary.md` чеклист или grep по `type":"telemetry"`.

## Решение в ретро

**continue / change / stop** по сигналам: доля usable ≤3 мин, публикация без сильных правок, добровольный возврат — не vanity metrics.
