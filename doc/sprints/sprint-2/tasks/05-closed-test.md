# 05 — Закрытый тест №1

Проверить не техническую новизну, а пригодность готовой карусели к публикации.

**Фича:** измерение F1.7 · **Зависимости:** end-to-end tasks 01–04

## Выборка и сценарий

- 10–20 пользователей: SMM, эксперты и риелторы
- Каждый создаёт минимум одну реальную карусель; модератор не ведёт за руку
- Таймер начинается с `/start`, заканчивается первым результатом, который пользователь считает usable

## События и вопросы

- Этапы воронки, generation/render/delivery latency, ошибки и повторные попытки
- Понятен ли flow без объяснения?
- Можно ли выложить результат; что пришлось переписать?
- Хочется ли «другой вариант», сменить стиль или сделать ещё одну карусель?
- Был ли результат опубликован и вернулся ли пользователь самостоятельно?

## Done when

- [ ] Есть consent и минимальный test script без сбора лишних персональных данных
- [ ] Для каждого участника записаны сегмент, completion, total time и outcome
- [ ] Можно посчитать долю usable ≤3 минут и основные точки drop-off
- [ ] Качественная обратная связь сгруппирована по content, visual, bot UX и reliability
- [ ] Зафиксированы критические блокеры Sprint 3 и запросы вне scope
- [ ] В ретро Sprint 2 принято решение continue/change/stop с опорой на данные
