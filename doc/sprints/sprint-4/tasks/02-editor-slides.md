# 02 — Редактор слайдов

Текст, порядок, add/delete — без drag Canva.

**Фича:** F2.2 · **Зависимости:** task 01

## Scope

- Edit headline/body/CTA полей активного type
- Reorder, add (из разрешённых types), delete с минимумом 2 слайдов (hook+cta)
- Сохранение → новая immutable version (как в S3)

- [ ] Правки проходят Zod; битый JSON не сохраняется
