# 04 — Theme picker (2 цвета)

**Фича:** F2.9 · **Зависимости:** S3 theme tokens, task 03

## Scope

- UI: фон + акцент; muted / surface / onAccent — авто
- WCAG ≥ 4.5:1 для текста; иначе предупреждение или авто-коррекция
- `onAccent` не редактируется вручную
- Free: 1 сохранённая своя тема; пресеты без лимита
- Сохранение в user Brand Theme (таблица/JSON), применение к project

## Done when

- [ ] Плохой контраст не проходит «в проде» незаметно для пользователя
- [ ] Своя тема переживает reload и доступна в новом project
- [ ] Нет палитры из лого и нет multi-theme UI (S5–6)
