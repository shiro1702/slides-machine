Выдай список шаблонов-стилей и отдельно список типов слайдов которые можно использовать для старта

Отличный вопрос — это как раз тот случай, где важно разделить две независимые оси:
Стиль (template)  = КАК выглядит (цвета, шрифты, фон, декор)
Тип слайда (slide type) = ЧТО на нём (структура контента)

Любой тип слайда должен рендериться в любом стиле. Тогда 8 стилей × 12 типов = 96 комбинаций из небольшого набора кода.

Часть 1. Шаблоны-стили для старта
Для MVP достаточно 6–8 стилей. Больше — распыление, меньше — скучно.
1. Clean Minimal
Фон:      белый / светло-серый
Шрифт:    гротеск (Inter, Golos)
Акцент:   один цвет (чёрный + 1 акцент)
Декор:    почти нет, много воздуха
Для кого: эксперты, консультанты, B2B

2. Dark Premium
Фон:      тёмный (#0E0E10 – #1A1A2E)
Шрифт:    контрастный, крупный
Акцент:   золото / бирюза / неон
Декор:    тонкие линии, градиентные пятна
Для кого: наставники, финансы, недвижимость премиум

3. Bold Marketing
Фон:      яркий цвет (жёлтый, оранжевый, красный)
Шрифт:    очень крупный, жирный, uppercase
Акцент:   контрастные плашки под текстом
Декор:    стрелки, подчёркивания, стикеры
Для кого: SMM, инфобиз, промо, скидки

4. Soft Pastel
Фон:      пастель (беж, розовый, лаванда, mint)
Шрифт:    мягкий, средний вес, можно serif-заголовки
Акцент:   приглушённые тона
Декор:    округлые формы, мягкие тени
Для кого: психологи, коучи, wellness, бьюти

5. Editorial / Journal
Фон:      кремовый / белый
Шрифт:    serif-заголовки + гротеск-текст
Акцент:   чёрный, бордовый
Декор:    линии-разделители, номера страниц, «журнальная» вёрстка
Для кого: личный бренд, лайфстайл, авторские блоги

6. Corporate Business
Фон:      белый / светло-синий
Шрифт:    строгий гротеск
Акцент:   синий / тёмно-зелёный
Декор:    сетка, иконки, диаграммные элементы
Для кого: B2B, юристы, финансы, агентства

7. Photo Overlay
Фон:      фото пользователя + затемнение/градиент
Шрифт:    крупный белый текст поверх
Акцент:   плашка или градиент снизу
Декор:    минимум, фото — главное
Для кого: риелторы, travel, товары, кейсы «до/после»

8. Neon / Tech
Фон:      тёмный с градиентом
Шрифт:    гротеск, местами mono
Акцент:   неоновый (фиолет, cyan)
Декор:    glow, сетка, «терминальные» элементы
Для кого: IT, AI-тематика, digital, крипта

Как описывать стиль в конфиге
Каждый стиль — это JSON-токены, а не отдельный код:
{
  "id": "dark_premium",
  "name": "Dark Premium",
  "colors": {
    "background": "#111114",
    "text": "#FFFFFF",
    "accent": "#E8C468",
    "muted": "#8A8A93"
  },
  "fonts": {
    "heading": "Unbounded",
    "body": "Inter"
  },
  "shapes": {
    "radius": 24,
    "decor": "gradient_blob"
  },
  "textCase": "normal",
  "padding": 96
}

Тогда добавление нового стиля = новый JSON + пара декоративных ассетов.

Часть 2. Типы слайдов для старта
Для MVP достаточно 10–12 типов. Из них собирается почти любая карусель.
Обязательные (без них нельзя запускаться)
1. Hook / Обложка
Роль:      первый слайд, останавливает скролл
Контент:   крупный заголовок + опционально подзаголовок
Пример:    «5 ошибок при покупке квартиры»
           «И как их избежать → листай»

2. Text Slide / Тезис
Роль:      одна мысль на слайд
Контент:   заголовок + 2–4 строки текста
Пример:    «Ошибка №1: смотреть только на цену»
           + короткое пояснение

3. Numbered Point / Пункт списка
Роль:      элемент серии «5 ошибок», «7 способов»
Контент:   крупная цифра + заголовок + пояснение
Пример:    большая «3» + «Игнорировать документы»

4. Checklist / Чеклист
Роль:      список с галочками/крестиками
Контент:   заголовок + 3–6 пунктов ✓/✗
Пример:    «Проверьте перед сделкой:» + 5 пунктов

5. CTA / Финальный слайд
Роль:      последний слайд, призыв к действию
Контент:   призыв + @username / стрелка «сохрани»
Пример:    «Сохрани, чтобы не потерять»
           «Подпишись → @realty_expert»

Сильно желательные (добавляют разнообразие)
6. Quote / Цитата
Роль:      цитата, ключевая мысль крупно
Контент:   текст в кавычках + опционально автор
Пример:    «Квартиру покупают глазами, а теряют — документами»

7. Myth vs Fact / Миф–Правда
Роль:      разрушение заблуждения
Контент:   блок «Миф» + блок «Реальность»
Пример:    Миф: «Ипотека — это всегда кабала»
           Факт: «Ставка субсидий может быть ниже инфляции»

8. Before / After — До и После
Роль:      контраст, трансформация
Контент:   две колонки или два блока
Пример:    «Было: 2 поста в месяц → Стало: контент каждый день»

9. Big Number / Статистика
Роль:      цифра как главный герой слайда
Контент:   огромное число + подпись
Пример:    «73%» + «покупателей не читают договор полностью»

10. Steps / Шаг инструкции
Роль:      пошаговый план
Контент:   «Шаг 2 из 5» + заголовок + описание
Пример:    «Шаг 2: Проверьте выписку из ЕГРН»

Опциональные (можно добавить во 2-й итерации)
11. Question / Вопрос-вовлечение
Роль:      слайд-вопрос для комментариев
Контент:   крупный вопрос + подводка
Пример:    «А вы бы купили квартиру без риелтора?»
           «Напишите в комментариях 👇»

12. Photo Slide / Фото-слайд
Роль:      фото пользователя + подпись
Контент:   изображение + заголовок поверх/снизу
Пример:    фото объекта + «2-комн., 54 м², от собственника»
Нужен:     для Photo Overlay стиля и риелторов

13. Comparison / Сравнение
Роль:      таблица «А vs Б»
Контент:   2 колонки с плюсами/минусами
Пример:    «Новостройка vs Вторичка»

14. Author / Кто я
Роль:      слайд-визитка перед CTA
Контент:   имя, регалии, чем полезен
Пример:    «Меня зовут Анна, 8 лет в недвижимости, 200+ сделок»

Как это связывается вместе
AI генерирует карусель как последовательность типов:
{
  "theme": "dark_premium",
  "slides": [
    { "type": "hook",     "title": "5 ошибок при покупке квартиры" },
    { "type": "numbered", "number": 1, "title": "Смотреть только на цену", "text": "..." },
    { "type": "numbered", "number": 2, "title": "Не проверять документы", "text": "..." },
    { "type": "numbered", "number": 3, "title": "Торопиться со сделкой", "text": "..." },
    { "type": "big_number", "value": "73%", "caption": "покупателей не читают договор" },
    { "type": "checklist", "title": "Проверьте перед сделкой", "items": ["...", "..."] },
    { "type": "cta",      "text": "Сохрани, чтобы не потерять", "handle": "@realty_expert" }
  ]
}

А в промпте для LLM задаются паттерны структур:
Паттерн "Ошибки":    hook → numbered × N → big_number → checklist → cta
Паттерн "Инструкция": hook → steps × N → quote → cta
Паттерн "Мифы":      hook → myth_fact × N → text → cta
Паттерн "Кейс":      hook → before_after → steps × 3 → author → cta

Рекомендация по объёму на старт
Спринт 1–2 (MVP):
  Стили:  Clean Minimal, Dark Premium, Bold Marketing
  Типы:   hook, text, numbered, checklist, cta        (5 типов)

Спринт 3–4:
  Стили:  + Soft Pastel, Photo Overlay
  Типы:   + quote, myth_fact, big_number, steps       (9 типов)

Спринт 5+:
  Стили:  + Editorial, Corporate, Neon
  Типы:   + before_after, question, photo, comparison, author

3 стиля × 5 типов уже дают приличное разнообразие для первых тестеров, а главное — вы быстро увидите, какие стили реально выбирают, и будете добавлять следующие не вслепую, а по данным.

Надо добавить еще диаграммы может быть?
И можно ли будет самим менять шрифты?
И я думал делать цветовые темы (может быть несколько у одного Юзера) (tailwind theme) которые можно быстро менять под себя (например под цвет клиентов из из брендбука создавать слайды) цвета в темах настраивать самостоятельно или выбирать из палитры

Отличные мысли — все три идеи правильные. Причём цветовые темы — это вообще одна из сильнейших фич для монетизации (SMM-щики и агентства ведут по 5–10 клиентов, каждому нужен свой брендбук). Разберу по порядку.

1. Диаграммы — да, но простые
Полноценные charts (как в Excel) не нужны. Нужны «инфографические» слайды — они выглядят эффектно, а данных требуют минимум.
Типы диаграмм-слайдов для старта
1. Progress Bars / Горизонтальные бары
Контент:  заголовок + 3–5 строк «название + %»
Пример:   «Куда уходит бюджет на ремонт»
          Материалы    ████████░░ 45%
          Работа       ██████░░░░ 35%
          Мебель       ███░░░░░░░ 20%
Сложность рендера: низкая 🔥 начать с этого

2. Big Percent / Donut
Контент:  одна цифра + кольцевая диаграмма + подпись
Пример:   кольцо 73% + «покупателей не читают договор»
Сложность: низкая (SVG-круг с stroke-dasharray)

3. Bar Chart / Столбцы сравнения
Контент:  3–5 столбцов с подписями
Пример:   «Средняя цена м² по районам» — 4 столбца
Сложность: средняя

4. Timeline / Таймлайн
Контент:  вертикальная линия + 3–5 точек с датами
Пример:   «Как проходит сделка: день 1 → день 30»
Сложность: низкая

5. Pie / Структура
Контент:  круг из 3–4 секторов + легенда
Сложность: средняя, можно отложить

Важные принципы
1. Максимум 5 значений на слайд — это соцсети, не отчёт
2. Данные вводит пользователь ИЛИ генерирует AI из темы
3. Рендер через SVG/HTML — идеально ложится и в web-preview, и в Remotion
4. Цвета диаграммы берутся из активной темы автоматически
5. Для рилсов бары/donut красиво анимируются (рост от 0 до значения)

Последний пункт — бонус: анимированная диаграмма в рилсе выглядит дорого, а делается дёшево.
JSON-схема
{
  "type": "chart_bars",
  "title": "Куда уходит бюджет на ремонт",
  "items": [
    { "label": "Материалы", "value": 45 },
    { "label": "Работа",    "value": 35 },
    { "label": "Мебель",    "value": 20 }
  ],
  "unit": "%"
}

Рекомендация: в MVP добавить progress_bars и big_percent — максимум эффекта при минимуме кода. Остальное во 2-ю итерацию.

2. Шрифты — да, но из курируемого списка
Почему не «загрузи любой шрифт» сразу
1. Лицензии: пользователь зальёт коммерческий шрифт → риски у вас
2. Кириллица: половина шрифтов её не имеет → битые слайды
3. Рендер: шрифт нужен и на клиенте (preview), и на сервере (Remotion) —
   синхронизация произвольных файлов усложняет пайплайн
4. Вёрстка: шаблоны свёрстаны под определённые пропорции —
   случайный шрифт может ломать переносы и размеры

Правильная схема для MVP
Курируемый список из 10–15 пар (заголовок + текст), все с кириллицей, все Open Source (Google Fonts / OFL):
Гротески (универсальные):
  Inter, Golos Text, Manrope, Onest, Unbounded

Экранные/акцентные:
  Bebas Neue (кир. версия), Russo One, Oswald

Serif (editorial):
  Playfair Display, Lora, PT Serif

Моно (tech):
  JetBrains Mono

Пользователь выбирает не отдельные шрифты, а пару:
{
  "fontPair": {
    "id": "modern_bold",
    "heading": "Unbounded",
    "body": "Inter"
  }
}

Так вы гарантируете, что сочетание всегда выглядит хорошо.
Уровни доступа (сразу заложить в тарифы)
Free:  3 пары шрифтов
Pro:   все 15 пар + размер/межстрочный интервал
Agency (позже): загрузка своего шрифта (.ttf/.woff2)
                + чекбокс «подтверждаю права на использование»

Загрузка своих шрифтов — реальная фича для агентств (у клиентов брендовые шрифты), но технически: валидация файла, проверка кириллицы, доставка в render worker. Это версия 2–3, не MVP.

3. Цветовые темы — да, это killer feature 🔥
Ваша интуиция верная, и я бы поднял ставку: это не просто «настройка», это Brand Kit — основа тарифа для SMM-щиков и агентств.
Архитектура: разделить стиль на два слоя
Сейчас у нас «стиль» = цвета + шрифты + декор вместе. Правильнее разрезать:
Layout Style (от нас):   вёрстка, декор, композиция, характер
                          → Minimal, Bold, Editorial, Photo Overlay...

Brand Theme (от юзера):  цвета + шрифты + логотип + @handle
                          → «Мой блог», «Клиент: Кофейня», «Клиент: Автосалон»

Любой Layout × любая Theme = валидный результат. Пользователь один раз настроил тему клиента — и все карусели/рилсы для него автоматически в фирменных цветах.
Схема темы (Tailwind-подобные токены)
{
  "id": "theme_client_coffee",
  "name": "Кофейня Roast",
  "colors": {
    "background": "#F5EFE6",
    "surface":    "#FFFFFF",
    "text":       "#2B1D14",
    "textMuted":  "#8A7A6D",
    "accent":     "#C46A2B",
    "onAccent":   "#FFFFFF"
  },
  "fontPair": "editorial_soft",
  "logo": "https://blob.../logo.png",
  "handle": "@roast.coffee",
  "darkVariant": false
}

Шаблоны внутри используют только токены, никогда — конкретные hex:
<Slide bg="var(--background)">
  <Title color="var(--text)" />
  <Badge bg="var(--accent)" color="var(--onAccent)" />
</Slide>

Тогда смена темы = мгновенная перекраска всего проекта.
UX создания темы
Способ 1 — из пресетов:
  20–30 готовых палитр, выбрал → сохранил под своим именем

Способ 2 — свои цвета:
  color picker на 2 главных цвета (фон + акцент),
  остальные (muted, surface, onAccent) генерируем автоматически
  с проверкой контраста

Способ 3 — из логотипа 🔥:
  пользователь загружает лого клиента →
  извлекаем доминирующие цвета →
  предлагаем 3 варианта палитры
  (простая фича, а выглядит как магия)

Способ 4 (позже) — из ссылки:
  дать URL сайта/Instagram клиента → вытянуть цвета

Два критичных нюанса
Контраст
Пользователь выберет жёлтый текст на белом фоне — и обвинит вас, что «некрасиво». Поэтому:
- автопроверка контраста (WCAG, отношение ≥ 4.5:1 для текста);
- если контраст плохой → авто-коррекция или предупреждение;
- onAccent (цвет текста на плашках) считаем сами, не даём выбрать вручную.

Лимиты по тарифам
Free:   1 своя тема + пресеты
Pro:    5 тем
Agency: 20+ тем + шрифты клиентов + лого на слайдах

Количество тем = количество клиентов у SMM-щика. Это самый естественный триггер апгрейда на дорогой тариф.

Как всё складывается вместе
Итоговая модель проекта:
{
  "layout": "bold_marketing",
  "theme": "theme_client_coffee",
  "slides": [
    { "type": "hook",          "title": "5 мифов о кофе" },
    { "type": "myth_fact",     "myth": "...", "fact": "..." },
    { "type": "progress_bars", "title": "Что пьют гости", "items": [] },
    { "type": "big_percent",   "value": 68, "caption": "выбирают капучино" },
    { "type": "cta",           "text": "Сохрани", "handle": "@roast.coffee" }
  ]
}

Три независимые оси:
Layout (вёрстка)  ×  Theme (бренд)  ×  Slide types (контент)
   8 стилей          ∞ юзерских         14 типов + 2 диаграммы

Обновлённый план по итерациям
MVP (спринт 1–2):
  - 3 layout-стиля
  - 5 типов слайдов
  - 6–8 пресетных цветовых тем (без кастома)
  - 3 пары шрифтов

Итерация 2 (спринт 3–4):
  - своя тема: 2 цвета через picker + автогенерация остальных
  - progress_bars + big_percent
  - выбор пары шрифтов из 10
  - @handle в теме (автоподстановка в CTA)

Итерация 3 (спринт 5–6):
  - несколько тем у юзера («под клиентов»)
  - палитра из логотипа
  - лого на слайдах
  - bar_chart, timeline
  - тарифные лимиты на темы/шрифты

Позже:
  - загрузка своих шрифтов (Agency)
  - извлечение палитры из сайта/Instagram
  - тёмный/светлый вариант одной темы

Главный совет: в MVP темы делайте пресетами, но в схеме данных сразу заложите кастомные токены. Тогда «Brand Kit для агентств» потом включится без миграций — а это ваш будущий самый дорогой тариф.
