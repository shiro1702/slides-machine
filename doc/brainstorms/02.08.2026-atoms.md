Следствие для данных: появляется Brand Kit
Раз автор/хэндл/аватар одинаковы на всех слайдах — это не данные слайда, это данные проекта/юзера:

JSON карусели теперь трёхуровневый:

{
  "brand": {                        ← уровень ЮЗЕРА (задал один раз)
    "handle": "@realtor.anna",
    "name": "Анна Смирнова",
    "role": "риелтор, 12 лет",
    "avatarUrl": "blob://...",
    "showAvatar": true
  },
  "settings": {                     ← уровень ПРОЕКТА
    "style": "clean_minimal",
    "theme": "ivory",
    "showCounter": true,
    "showAuthor": true,
    "label": "НЕДВИЖИМОСТЬ"         ← общий лейбл рубрики
  },
  "slides": [                       ← уровень СЛАЙДА (только контент!)
    { "type": "hook", "data": { "title": "..." } },
    { "type": "numbered", "data": { "number": 1, "title": "...", "text": "..." } }
  ]
}
Что это даёт продукту:

+ AI генерирует ТОЛЬКО контент слайдов — промпт проще, ошибок меньше
+ юзер один раз загрузил аватар и хэндл → во всех будущих каруселях
  (это и есть «бренд-кит» — фича, за которую платят в Pro)
+ тумблеры в редакторе: «номера слайдов вкл/выкл», «подпись вкл/выкл» —
  одна настройка меняет все слайды сразу
+ counter вообще вычисляется (index/total) — AI и юзер его не трогают
Структура пакета с учётом атомов
/packages/slides
   /tokens            цвета, шрифты, spacing
   /atoms             SlideCounter, AuthorBadge, Label, Hairline,
                      AccentBar, ProgressDots, GhostNumber, Chip,
                      CardSurface, Check, QuoteMark, SwipeHint, ArrowFlow
   /chrome
      SlideFrame.tsx  слоты + поля + фон
   /templates         14 типов × варианты раскладки контента
      HookLeftAxis.tsx, HookCentered.tsx, NumberedGhost.tsx, ...
   /styles
      clean_minimal.ts, bold_impact.ts, dark_premium.ts, ...
      (tokens + atom variants + chromeLayout)
   renderSlide.tsx    (type, variant, data, style, brand) → JSX
Экономика этого решения
Без атомов:  14 типов × 3 варианта × 5 стилей = 210 реализаций служебки
С атомами:   14 атомов × ~3–4 варианта каждый = ~50 маленьких кусочков,
             шаблоны собирают их бесплатно

Новый стиль = токены + мэппинг вариантов атомов (~1 файл, полдня)
Новый тип слайда = только контентная часть (~полдня)
Правка «подвинуть хэндл» = 1 место (SlideFrame/AuthorBadge)
И бонус для рендера: атомы — чистый React, значит одинаково работают в редакторе, html-to-image и Remotion. А когда придут рилсы — анимируются атомарно же («counter fade-in», «hairline растёт слева») один раз для всех шаблонов.
