Давай прикинем как будут выглядеть все 14 типов слайдов (с тремя разными вариантами на каждый тип) в стиле clean minimal с учетом замены цветов primary secondary и прочих.

Скопировать
Отличный способ проверить систему на прочность — прогнать весь набор типов через один стиль. Заодно увидим, хватает ли токенов темы. Погнали.

ДНК стиля Clean Minimal (правила для всех слайдов)
Сетка:        поля 96px со всех сторон (1080×1350)
Типографика:  заголовки weight 500–600 (не жирнее!), текст 400
              лейблы — КАПС, letter-spacing 0.08em, 28–30px
              display 120–170px · h1 64–80px · body 38–44px
Декор:        только hairline-линии (2px), точки, тонкие кольца.
              Ни теней, ни градиентов, ни заливок больших площадей
Акцент:       accent занимает ≤ 10% площади слайда. Одна деталь.
Служебное:    номер слайда «03 — 07» моно-капсом в углу, textMuted
Роли токенов в этом стиле
background   основной фон всех слайдов (кроме CTA-инверсии)
surface      карточки-подложки (на 1 тон отличается от фона)
text         заголовки и основной текст
textMuted    подписи, лейблы, вторичный текст, номера
accent       ТОЧЕЧНО: линия, точка, галочка, одно слово, цифра
onAccent     текст на accent (нужен только в CTA-B и мелких плашках)
line         производный: text с opacity 10% — все hairline'ы
Легенда для макетов
ЗАГОЛОВОК     = text, крупно        ▓▓▓  = заливка accent
обычный текст = text, body          ○ ●  = точки прогресса
серый текст   = textMuted           ────  = hairline (line)
[МЕТКА]       = капс-лейбл          ┃    = accent-линия 4px
