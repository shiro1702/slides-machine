## Ключевые решения

1. **Один пакет слайдов** (`packages/slides` / текущий `remotion/layouts`) — чистый React; web preview, html-to-image и Remotion едят одно и то же.  
2. **Сервер = Remotion** (`renderStill` / позже `renderMedia`), не Playwright и не второй CSS-движок.  
3. **Гибридный экспорт:** клиентский ZIP (дёшево) + серверный альбом в мессенджер (удобство / Pro / рилсы).  
4. **Мессенджер = тонкий адаптер;** Core + `user_identities` с первого архитектурного дня; TG — единственная реализация в MVP.
