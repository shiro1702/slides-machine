## Ключевые выводы (новое)

1. **Проверка системы** — прогнать все типы через один стиль (`clean_minimal`) и убедиться, что токенов темы хватает (`background` … `line`).
2. **У каждого типа — 3 layout-варианта** (A/B/C раскладки контента), не три разных «стиля».
3. **Дизайн-система трёх слоёв:** TOKENS → ATOMS → TEMPLATES. Шаблон не рисует счётчик/хэндл сам — только собирает атомы.
4. **SlideFrame** — общая рама со слотами (topLeft/topRight/content/bottomLeft/bottomRight); chromeLayout — часть layout-стиля.
5. **JSON трёхуровневый:** `brand` (юзер) · `settings` (проект) · `slides[]` (только контент). AI генерит только slides.
6. **Экономика:** без атомов ~210 реализаций служебки; с атомами ~50 кусочков + сборка. Новый стиль = токены + variant-map (~полдня).
